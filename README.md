## About

I build and evolve production software end to end, with **8+ years of experience** across mobile, web, backend, APIs, data and infrastructure. Mobile engineering is my deepest specialization, particularly **React Native / Expo**, while I also work extensively with **React / Next.js, TypeScript / Node.js and PHP / Laravel**.

My work goes beyond feature implementation: architecture, offline-first systems, multitenancy/white-label, databases, integrations, CI/CD, reliability, performance, app-store delivery and production operations are all part of the same product lifecycle. I also have recent experience in **hands-on technical leadership**, code review, mentoring and product ownership.

### What I usually work on

- **Mobile Engineering:** React Native / Expo, Android/iOS architecture, offline synchronization, native integrations, releases and store publishing.
- **Full Stack:** React, Next.js, TypeScript, Node.js/NestJS, PHP/Laravel, REST APIs, WebSockets and integrations.
- **Data & Backend:** PostgreSQL, SQL Server, MySQL/MariaDB, MongoDB, Redis, Firebase, modeling, query tuning, queues and asynchronous processing.
- **Delivery & Reliability:** Docker, CI/CD, AWS/Azure/VPS, testing, observability, backups, rollback/recovery, load balancing and production support.
- **Technical Leadership:** architecture decisions, PR/code review, mentoring, documentation and translating product/business needs into executable technical work.
